# Этап 5. Есть ли в новости инсайт для бизнеса?

Вход — новости, прошедшие этап 4. Здесь решается, есть ли **инсайт**, а не пересказ: конкретный факт о компании,
механизм влияния, позиция Банка, подтверждение из других источников. Для этого агент возвращается к пулу новостей
за дополнениями и ищет в аналитике Банка. Выход — `InsightDecision` для этапа 6.

| Подход | Папка | Суть | Статус |
|---|---|---|---|
| Дополнения из пула новостей | [`news_enrichment/`](news_enrichment/related_news.py) | `RelatedNews`: другие сообщения того же события (кластеры этапа 4), последующие новости по теме (развитие, официальное подтверждение), свободный поиск | ✅ работает |
| Аналитика Банка | [`bank_analytics/`](bank_analytics/) | PDF Банка — сканы без текстового слоя. `ocr.py`: PyMuPDF рендерит страницу → Qwen3-VL переписывает текст (промпт `prompts/ocr_page.md`, кеш по странице). `search.py`: `BankAnalytics` — поиск по абзацам с отчётом, датой и страницей; свежий отчёт выше, отчёты старше года помечены `stale` и идут в конец. `reports.json` — даты отчётов | ✍ OCR без запуска; поиск проверен на синтетике |
| Разбор аналитики Банка | [`bank_analytics/library.py`](bank_analytics/library.py), [`match.py`](bank_analytics/match.py) | Загрузчик по папке: фрагменты с темами, числами, собственной позицией Банка и свежестью на дату проверки; подбор фрагментов под событие и профиль компании | ✅ офлайн-тест на синтетике |
| Агентный цикл аналитики Банка | [`analyst_loop/`](analyst_loop/README.md) | Задачи 1–8: подбор аналитики, возврат к пулу новостей, запросы недостающих данных, последствия и риски (код), проверка оснований, вердикт → писатель → аудит; журнал JSONL | ✅ офлайн-тест `analyst_loop/test_analyst_loop.py`; с реальной моделью не запускался |
| Судья инсайта (LangGraph) | [`insight_judge/`](insight_judge/judge.py) | `InsightJudge`: подцикл `ToolLoop` с инструментами `same_event_reports`, `follow_up_news`, `search_news`, `search_bank_analytics`, `company_facts`; завершается `decide` → `InsightDecision` (инсайт или нет, 0–3, связь с фактом, механизм, позиция Банка, подтверждающие новости, чего не хватает). Самопроверка в промпте: факт, механизм, позиция Банка, противоречия | ✍ офлайн-тест в `test_pipeline.py` |

У judge есть необязательный инструмент `compute`: доля выручки компании в группе, разница сопоставимых показателей
новости и Банка, сценарий «выручка × прогноз в %», перевод единиц. Он использует Python-калькулятор из
[`analyst_loop/compute.py`](analyst_loop/compute.py), без отдельного агента и без собственного поиска.
Для банковских расчётов используются исходные фрагменты уже выполненного `search_bank_analytics`; для выручки —
структурированная карточка Кирилла, загружаемая только при таком расчёте. Результаты с формулой, источниками и
допущениями передаются автору карточки и аудиту; сценарий остаётся гипотезой. Дополнительное время LLM возможно
на запрос и чтение результата инструмента; новость без арифметики проходит обычным путём.

Банковские материалы, прочитанные judge, передаются writer и финальному аудиту: найденные чанки,
соседние чанки окна и показанные похожие таблицы. Для каждого сохраняются ID, текст, страницы, дата,
свежесть и собственный признак `own_view`; соседняя статистика не наследует признак прогноза.
Повторный поиск по механизму нужен только если judge не прочитал банковских материалов.
Прочитанные чанки передаются writer целиком, без прежнего ограничения 900 символов; окна инструмента
также не обрезаются по символам поверх ограничения количества чанков. Повторы источников удаляются по ID
в пределах одной новости. Это может увеличить текстовый контекст LLM, но не добавляет вызовов агента или энкодера.

**Golden set**: пока нет. Предложение — метки «инсайт / не инсайт» с причиной на стратифицированной выборке
(событие × компания) из пула этапа 4, согласие двух разметчиков; контрфакт: подмена компании → решение меняется.

```bash
python -X utf8 stage5_insight_detection/news_enrichment/related_news.py 5711
python -X utf8 stage5_insight_detection/bank_analytics/ocr.py        # нужен LLM_API_KEY
python -X utf8 stage5_insight_detection/bank_analytics/search.py "ключевая ставка прогноз"
```
