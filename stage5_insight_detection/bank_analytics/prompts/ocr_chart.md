Это один график из аналитического отчёта Альфа-Банка. Перенеси его в JSON. Никаких догадок: только то, что напечатано или
однозначно читается.

Правила:
1. printed_values — только числа, напечатанные на картинке: подписи данных, значения у последних точек, подписи столбцов.
   Каждое — с рядом (series) и точкой (x: дата или категория, как подписано). Число пиши как на картинке (запятая, знак, %).
   Если на графике нет напечатанных значений — пустой список. Не вычисляй и не оценивай значения по шкале.
2. Для каждого ряда: trend_period — направление за весь период (рост / снижение / без изменений / разнонаправленно),
   trend_end — направление на последнем участке. last_point — положение последней точки относительно ближайших делений
   шкалы («между 14,0 и 14,5»), только если оно читается однозначно; иначе «не определить».
3. Оси: перепиши все подписанные деления (ticks) как напечатано, подпись оси и единицы; для оси X — первую и последнюю
   подписанную дату или категорию. Вторая ось — y2_axis, если есть, иначе null.
4. Для каждого ряда color — цвет его образца в легенде одним словом: красный, чёрный, серый, зелёный, жёлтый, синий,
   розовый, другой; style — линия, пунктир, линия с маркерами, столбцы, столбцы с накоплением, область.
5. Источник — строка «Источник…» под графиком, если видна, иначе "".

Ответ — только JSON без пояснений, по схеме:
{{"title": "...", "type": "линия|столбцы|комбинированный|круговая|область|другое",
 "x_axis": {{"label": "...", "first": "...", "last": "...", "ticks": ["..."]}},
 "y_axis": {{"label": "...", "unit": "...", "ticks": ["..."]}},
 "y2_axis": null,
 "series": [{{"name": "...", "printed_values": [{{"x": "...", "value": "..."}}],
             "trend_period": "...", "trend_end": "...", "last_point": "...", "color": "...", "style": "..."}}],
 "source": "..."}}
