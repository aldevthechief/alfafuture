# Выборочная интеграция Вовчика

Источник — локальная Git-ветка `vladimir-all`, коммит `38fd105`. ZIP не использовался.
Изменения адаптированы поверх `integration/kirill-vovchik`, исходная база `d04a6a8`.

## Что подключено

- `analyst_loop/impact.py`: запрет переноса бензина на дизельные затраты и недельного/дневного изменения на годовой
  бюджет; отраслевая доля ФОТ как явное допущение; `level_why` в последствиях, журнале и критериях карточки.
- `analyst_loop/compute.py`: расчёты по запросам `computation` — разница сопоставимых показателей, доля компании
  в выручке группы, перевод единиц, сценарий «выручка × прогноз». Код возвращает формулы и основания. Сценарий,
  отраслевые доли и число, предложенное моделью для перевода единиц, не выдаются за исходные факты.
  Результаты дозапросов сохраняются между раундами и доходят до автора инсайта.
- `bank_analytics/charts.py`, `digitize.py`, `chart_reading.py`: границы соседних графиков, восстановление месячных
  точек по прослеженной линии, уточнение калибровки шкалы и легенды, прогнозные периоды. Значения, снятые по пикселям,
  остаются приблизительными; определение будущего периода не превращает их в проверенные числа.
- `bank_analytics/theses.py`: отбор собственных актуальных тезисов Банка, срок жизни по типу отчёта, сопоставление
  с компанией, защита от повторов и лимит отдельных банковских карточек. Чужая цитата и устаревшая выжимка не становятся
  позицией Банка. При отсутствии пригодной выжимки используются собственные формулировки отчёта.
- `loop.run_thesis`, `bank_run.py`: банковские инсайты без исходной новости, с реальными ссылками `bank:…` и без
  фиктивного `news_id`. Автор сохраняет цитаты и смещения в исходном банковском фрагменте. В карточке указан источник
  «Из аналитики Банка». Если тему уже покрывает готовый новостной инсайт, тезис добавляется в его позицию Банка.

## Совместимость

- Оба пути через `pipeline.py` и самостоятельный `bank_run.py` используют профили Кирилла. Выжимка профиля остаётся
  пояснением, а чувствительности — гипотезами; они не подменяют исходные факты и ранжирование Максона.
- Сохранены v2/v3, фабрика запросов, снимки новостного корпуса, потоки judge, полные факты для автора и аудита,
  настройки моделей, две переработки текста, проверка дословных цитат, ограничения бюджетов и обработка ошибок PDF.
- `foreign_number`, новая тотальная сверка новостей с числами Банка и безусловный отказ при всех `low` не добавлены.
  Существующий путь возврата к аналитике после отказа модели сохранён. Инструмент расчётов подключён к `loop`;
  инструменты `judge` не менялись.
- В обычном запуске банковские тезисы не запускаются. Нужен явный флаг или отдельная команда.

## Запуск после проверки изменений

Команды ниже обращаются к реальным моделям при настроенных ключах. В ходе интеграции они не запускались.

```powershell
# Новости и дополнительные тезисы Банка
python -X utf8 pipeline.py U_3263 --engine loop --retrieval v3 --bank-insights

# Только тезисы, без news.parquet; профиль компании берётся из profiles.jsonl или CSV
python -X utf8 stage5_insight_detection/analyst_loop/bank_run.py U_3263 --budget 5
```

`bank_run.py` сохраняет JSON, карточку и сводку после каждого результата. Перед следующим тезисом проверяется резерв
не меньше 1 ₽ и не меньше максимальной цены уже выполненного тезиса. Это остановка между инсайтами по наблюдаемым
затратам, а не гарантия цены ещё не выполненного запроса к модели. Результаты, уже сохранённые до остановки, остаются.
В обычном пайплайне действуют его существующие настройки бюджетов.

Новая обрезка имеет версию кеша. При явном запуске этапа графиков старые обрезки перечитываются; успешные новые ответы
кешируются. Если новое чтение завершилось ошибкой, прежняя обрезка и JSON сохраняются. Предыдущие версии assets
архивируются существующим механизмом. Перестроение библиотеки учитывает новую версию парсера и изменения assets.
