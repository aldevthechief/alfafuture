# Индикаторы новостей и инсайтов

Индикатор — отображение уже готового персонального анализа. Его вычисляет обычная функция
`frontend/src/insightSignal.js`: дополнительных агентов, LLM-запросов и изменений графа нет.
Правила одинаковы для новостей и аналитики Банка, карточки, главного экрана и полного окна.

| Существующие данные | Отображение |
|---|---|
| `risks` есть, `opportunities` нет | 🐻 «Риски для компании», красный фон и акцент |
| `opportunities` есть, `risks` нет | 📈 «Возможности для компании», зелёный фон и акцент |
| Есть оба блока | ⚠️ «Риски и возможности», красный акцент: риски требуют внимания |
| Нет обоих блоков | 📰 «Без оценки направления», нейтральное оформление |
| `impact.level === 'high'` | Дополнительно 🔥 «Высокое влияние», независимо от цвета |

Это направление влияния на выбранную компанию и роль, а не эмоциональная тональность текста
или прогноз рынка. Сочетание рисков и возможностей не сводится к разнице числа пунктов.
Уверенность (`confidence`) остаётся отдельной оценкой достоверности и не определяет цвет или 🔥.
Без `impact` высокая важность не предполагается.

Краткий API отдаёт только `counts` и `impact_level`; источники и полные материалы по-прежнему
загружаются при открытии. Существующие сохранённые анализы работают без повторного запуска.

Светлая/тёмная тема доступна на экране входа и в шапке кабинета. При первом посещении учитывается
системная тема, ручной выбор сохраняется в `localStorage` (`alfa-insights-theme`). Общие токены
оформляют кабинет и вход, встроенная тёмная палитра Core Components — также модальные окна,
поля, кнопки и другие компоненты, включая порталы.
