# Интерфейс прототипа и требования организаторов

Проверено по локально доступной ветке `origin/org-facts`, коммит
`99466f90212585152b423190bcc7f6f321228935`. Ветка прочитана через `git show`, без переключения и слияния.

Источники в этой ветке:

- `sources/qa-report/qa-report.txt`, вопросы 52–54 и 73: самостоятельный прототип допустим,
  точное копирование дизайн-системы не оценивается; нужны вход с главного экрана интернет-банка
  и аналитический раздел, который воспринимается как его часть.
- `sources/tg/org-answers.md`, ответ организатора №6463: связь с банком минимально реализуется
  точкой входа; остальной функционал определяет команда. Отдельная регистрация не обязательна.
- Там же, ответы №6591 и №6596: реальная тестовая интеграция недоступна;
  достаточно оформления в стилистике Альфа-Бизнеса и точки входа, детальная копия дизайна не требуется.
- `facts/ui.md`, U-20–29: интерфейс для среднего и крупного бизнеса, быстрый путь к пользе;
  избыточные анимации нежелательны. Это сводка; первичные ответы перечислены выше.

Вывод для нашего прототипа: полный набор банковских разделов воспроизводить необязательно.
Пустые пункты можно убрать, сохранив главную с заметным входом в инсайты, общий каркас кабинета,
выбранную компанию и роль, навигацию и единый визуальный язык. Это интерпретация требований,
а не отдельное прямое указание организаторов удалить банковское меню.

Полезный компактный набор: главная, инсайты, компания, платёжная аналитика, контрагенты,
календарь и чат. Удаление остальных разделов — отдельное продуктовое решение.
