# Этап 1. Набираем большой пул новостей

Обязательная часть ТЗ: парсер новостей из открытых источников. Выход — очищенный корпус `data/news/news.parquet`
(в репозитории: ~9 тыс. новостей за 31 день из 54 источников).

| Подход | Папка | Суть |
|---|---|---|
| Веб-скрапинг: sitemap + RSS + дневные архивы → загрузка текста → очистка | [`web_scraping/`](web_scraping/README.md) | `discover.py` находит URL за N дней, `fetch.py` скачивает и извлекает текст (trafilatura), `build.py` чистит: реальная дата со страницы, дедупликация, отсев оффтопа, деление на tier 1 (деловые, отраслевые, регуляторные) и tier 2 (общие СМИ) |

**Golden set**: нет. Качество корпуса контролируют счётчики в `build.py` (сколько отсеяно на каждом шаге) и
покрытие источников в `web_scraping/README.md`.

**Дальше**: Telegram-каналы, GDELT / CC-NEWS для глубины архива, регулярный инкрементальный запуск
(план — в `web_scraping/README.md`).
