# Golden set диалогового агента: неудачные ответы

`failed_answers.json` — ответы, где агент по инсайту ошибся (вопрос, ответ, класс ошибки, спорный фрагмент, ожидаемое поведение).
Пополнять по мере находок: новый объект в `examples`, класс ошибки — в `failure_types`.

| Класс | Метка | Что значит |
|---|---|---|
| `unsupported_company_claim` | недостоверный факт о компании | утверждение о нише, портфеле, сегменте или регионе компании без опоры на профиль |

Правила в промптах (`prompts/analyze.md`, `prompts/company_chat.md`) написаны под эти примеры;
`tests/unit/feedback_api/test_failed_answers.py` проверяет формат набора и что правило есть в промптах.
