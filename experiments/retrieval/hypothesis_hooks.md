# Крючки из гипотез research_agent: дают ли они новых кандидатов (U_106783, 21.10)

`hypothesis_hooks.py`, без LLM. Тот же гибрид, что у `new_generators.py`: e5-large-instruct + qwen3-emb-0.6b
с инструкцией и BM25 по леммам, RRF, событие = максимум по его новостям. Вход — 8 гипотез третьего живого прогона
агента (`data/companies/agent/U_106783.json`). Каждую гипотезу проверяли двумя способами:
- **raw** — текст гипотезы как запрос; так сейчас работает причина `hypothesis` в `candidate_generators`;
- **hook** — новостной угол, выведенный из гипотезы вручную: какое событие стало бы важным, если гипотеза верна.

Для каждого запроса взяты топ-10 событий. Каждое отмечено:
- C — есть ли оно в текущем наборе кандидатов при бюджете 200;
- N — есть ли оно в 10 предложенных генераторах (`analysis.md` §7);
- цели судьи v2 — 13 позитивов и 28 полезных негативов.

Оценка ниже — моё чтение заголовков и текстов, судья эти события не размечал. Таблица — `out/hypothesis_hooks_U_106783.csv`.

## Выводы
1. **Гипотезы дают новый класс кандидатов, а не новые позитивы старого класса.** Финансовые крючки — факторинг,
   ликвидность, контроль платежей — не пересекаются ни с текущими, ни с предложенными генераторами. При этом они
   находят 4–5 правдоподобных инсайтов для финдиректора и казначейства (4202, 1529, 7167, 1912). Ни одна из 41 цели
   судьи v2 в их топ-10 не попала: судья искал «спрос на продукцию», а это другой тип инсайта.
2. **Текст гипотезы как запрос — плохой генератор.** Это то, что делает `hypothesis` в `generators.py`. Гипотезы
   описывают структуру компании (анонимные U_…, «транзит», «вывод средств»), и поиск находит криминальную хронику.
   Работают только гипотезы с поисковой сущностью: иностранный собственник находит временное управление активами.
3. **Структурные гипотезы о зависимости не ищутся напрямую:** торговый дом U_92777 и импорт через него. Контрагенты
   анонимны, новость о них не найти. Остаётся только отрасль, а её уже покрывает `own_industry`.
4. **Правило для генератора из гипотез:** превращать гипотезу в **финансово-операционный крючок** по таблице
   «тип гипотезы → угол новостей», а не подавать её текст:
   - внешний фактор → рынок и ставки факторинга, дебиторка в отрасли;
   - крупные свободные потоки и самоплатежи → ставки депозитов и размещение ликвидности;
   - односторонние контрагенты → контроль банков и ФНС за платежами;
   - иностранный собственник → временное управление и изъятие активов.
   Вывести такой крючок может LLM: один дешёвый вызов на гипотезу.
5. **Для клиентского инсайта:** крючки из H3 и H7 подавать как «ужесточение контроля за платежами — проверьте
   контрагентов», а не как подозрение компании.
