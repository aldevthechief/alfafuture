# Этап 2. Набираем много фактов о компании

Обязательная часть ТЗ: по данным банка понять компанию или группу (отрасль, масштаб, положение, связи) как можно глубже.
Выход: проверенные **факты** и конкурирующие **гипотезы** о бизнес-модели. По ним этапы 3–6 связывают компанию с новостями.

| Подход | Папка | Суть | Статус |
|---|---|---|---|
| Детерминированные факты | [`deterministic_facts/`](deterministic_facts/facts.py) | Код по таблицам: карточка, ранги, группа, физлица, платежи, второй уровень цепочки → `data/companies/facts.jsonl`. Только факты: отсутствие данных не превращается в строку, направление по ФТС не выдумывается | ✅ 9 компаний за 8 с |
| Агент исследования (LangGraph, GLM-5.3-Flash) | [`research_agent/`](research_agent/README.md) | Стартует от фактов кода, сам ходит в таблицы, формулирует гипотезы и пытается их опровергнуть в подграфе; память в состоянии графа, сжатие контекста | ✍ офлайн-тест; с моделью не запускался |
| Факт-паттерны и архетипы | [`business_patterns/`](business_patterns/report.md) | 90 признаков на компанию → 44 факт-флага → устойчивые сочетания (NMF + бутстреп) → 20 паттернов, сопоставленных с 22 архетипами бизнеса. Основа «правды по построению» для оценки гипотез агента | ✅ исследование 20.10; однозначных совпадений с архетипом 2 |

## Golden set — [`golden_set/`](golden_set/README.md)
- `company_facts_golden.json` — 9 компаний (ОКВЭД 41.20 / 62.01 / 56.10 × лидер / ~топ-20% / ~топ-70%).
  По каждой проверенные факты (с `keys` для подсчёта покрытия) и 2–4 гипотезы со статусом, доводами за и против
  и тестом на опровержение.
- Покрытие фактов скриптом: `coverage.py` → 65/65. Это оптимистично: golden set составлялся после просмотра выхода скрипта.
- Гипотезы — целевая разметка для агента, скрипт их не порождает.
- `industry_context.json` — отраслевой контекст трёх ОКВЭД (тренды, ссылки на новости). Это справочник, не golden set.

```bash
python -X utf8 stage2_company_facts/deterministic_facts/facts.py --ids U_76122 U_44767
python -X utf8 stage2_company_facts/golden_set/coverage.py
python -X utf8 stage2_company_facts/research_agent/test_agent.py
```
