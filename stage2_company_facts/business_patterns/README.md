# Факт-паттерны компаний и архетипы бизнеса

Поиск типов компаний с двух сторон: архетипы из теории и российской практики и паттерны строго из фактов
(таблицы + граф платежей), затем их сопоставление. Полный разбор и выводы — в [report.md](report.md).

| Файл | Что |
|---|---|
| `features.py` | 90 признаков на компанию: карточка, группа, физлица, форма видимого потока платежей (доли, концентрация, отрасли и регионы контрагентов, взаимность, PageRank) → `data/companies/features.parquet` |
| `patterns.py` | 44 факт-флага; поиск устойчивых сочетаний (NMF + бутстреп, `--discover 46 12`); каталог 20 паттернов со статистикой: lift, cohesion, обогащение ОКВЭД, крупные компании, проверка на частичную видимость → `data/companies/patterns.parquet`, `pattern_members.parquet` |

Главное ограничение: платежи видны в основном у клиентов банка. Поэтому анализ идёт по 16,5 тыс. «наблюдаемых»
компаний, из 115 крупных наблюдаемы только 57.

```bash
python -X utf8 stage2_company_facts/business_patterns/features.py   # ~40 с
python -X utf8 stage2_company_facts/business_patterns/patterns.py [--discover 41,42,43 12]
```
