# Расширение профиля: из одной строки CSV — максимум связанной информации

[`expand.py`](expand.py) — «снежный ком» (pseudo-relevance feedback) по новостному пулу этапа 1, без LLM по умолчанию.

```bash
python -X utf8 stage2_company_facts/expansion/expand.py U_42222 U_31505          # -> data/companies/expansion/<id>.json, ~2 с
python -X utf8 stage2_company_facts/expansion/expand.py U_42222 --llm            # + 1 вызов дешёвой модели (трейс в Langfuse)
python -X utf8 stage2_company_facts/expansion/eval_expansion.py                  # recall на golden set этапа 3
```

1. **Зёрна (раунд 0)** — из профиля: товары и сырьё отрасли, виды деятельности, ключевые слова внешних факторов
   (вес = вес фактора), регион, страны ФТС. Каждое зерно относится к грани: `sector`, `chain` (отрасли контрагентов),
   `trade` (ФТС, иностранный собственник), `geo`, `macro`, `llm`.
2. **Раунд r** — поиск новостей по новым терминам (`common.search`, TF-IDF по основам), затем новые термины из найденного:
   слова и биграммы, частые в найденных новостях и редкие в корпусе.
3. **Защита от ухода темы**: термин принимается при поддержке ≥ 2 новостей и лифте ≥ 5 (в найденном в 5+ раз чаще,
   чем в корпусе); обратная связь — только из новостей, совпавших с ≥ 2 терминами, без шаблонных (≥ 20 заголовков
   с тем же началом: пресс-релизы биржи, «Курс юаня на…»); новость с раунда 1 принимается, только если похожа на зёрна
   своей грани не меньше медианы раунда 0; вес термина × 0.6 за раунд.
4. **Грани растут раздельно** и потом сливаются: громкая грань (курс, ипотека через контрагентов) не утаскивает остальные.
5. **Остановка**: меньше 3 новых терминов за раунд (насыщение) или лимит раундов (по умолчанию 2).

Выход: `terms` (термин, вес, раунд, грань, происхождение, новости-источники), `news` (id, заголовок, дата, источник,
скор, первый раунд, грани, термины, по которым найдена), `rounds` (по граням и раундам: сколько новых терминов и новостей).

Саму компанию не ищем: данные обезличены, расширение идёт только через отрасль, контекст и связи.
